# Studio Gap Analysis — DevQuest vs. alexanderrehm.com

*Generated June 26, 2026. Source: their public Studios Directory (studios.html) compared against our `STUDIOS` (mainland) + `DIRECTORY` (island) + `moon.json`.*

## The headline numbers

| | Count |
|---|---|
| Studios in their directory (unique) | **1,597** |
| Studios we list (mainland + island + moon) | ~270 |
| In their list, not in ours | **1,356** |
| ...of those, **flagged as hiring right now** | **448** |

So the "several hundred new studios" claim is real on paper — they list ~1,600 names. But that number is inflated by a lot of things that are **not game-development studios** (casino/slots vendors, VFX/film houses, hardware makers, esports orgs, outsourcing/QA shops, ad-tech, web3) and by **subsidiaries we already cover at the parent level** (every 2K, EA, Activision, Krafton, Bandai Namco, Sony first-party studio listed separately).

The genuinely useful takeaway is the curated list below: **real, standalone game studios that are hiring now and that we don't have.** I focused on the 448 hiring ones, since a studio with no open roles wouldn't show jobs on our board anyway.

## Follow-up — Tier 2 check + new fetchers (2026-06-26)

**Tier 2 (subsidiaries) — verified, no action needed.** Checked the live `jobs.json`: the parent boards already split out the marquee studios. Under the EA parent we already get Respawn (24 roles), Motive Montreal (13), DICE Stockholm (8), Maxis (7), Criterion (6), Ripple Effect (6), BioWare, PopCap, Firemonkeys, and more — via `deptAsStudio`. Adding these as separate ATS boards would only duplicate jobs and add zero new openings, so Tier 2 is intentionally skipped.

- Side-finding 1 (resolved): the "Activision lumped under one name" reading was a false alarm — the local `jobs.json` is a June 6 snapshot (three weeks stale), from before the `companySplit` / `(HQ)` code existed. The live site runs off the cloud's hourly data. Checked against the **live** Activision feed: the split logic is sound and currently matches Infinity Ward, Sledgehammer, and Elsewhere. The real gap was three Activision studios the map didn't cover — added **Beenox, Demonware, Digital Legends** to `companySplit` (2026-06-27). The live feed now resolves to 7 studios: Activision (HQ) 28, Elsewhere 14, Demonware 8, Infinity Ward 4, Sledgehammer 3, Beenox 3, Digital Legends 2.
- Side-finding 2: ZeniMax showed 0 roles in the (stale) local data; can't confirm current state from here. Worth a glance at the live Health tab after the next scrape.
- Note: the local data files (`jobs.json`, etc.) are intentionally never re-uploaded (the golden rule), so they drift from the live cloud copy — they're only a rough reference, not current truth.

**Personio fetcher — built.** Added `fetchPersonio` (public `search.json` feed) and promoted three studios from island to mainland: **Com2uS, KING Art, Travian Games**. The fetcher skips Personio's evergreen "initiative / speculative / open application" pools. Reusable for any future Personio studio. (No posted date in the feed, so those show date-n/a, same as EA.)

**HRMOS — kept as island link-outs.** GAME FREAK and Spike Chunsoft run on HRMOS, a Japanese ATS that serves Japanese-only HTML with no salary or posted-date feed, and most roles require JLPT N1. That's the same profile as our other JP studios (FromSoftware, Konami, Kojima, Level-5), which are all link-outs — so these stay link-outs too rather than importing low-quality, untranslated rows. Can revisit if we add JP-language support.
