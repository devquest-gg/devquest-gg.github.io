How the naughty-words / bot-spam problem is contained
🔒 Email-gated writes — every edit is tied to a magic-link-verified identity. Anonymous bot spam can't post at all.
🧱 Controlled vocab — skills & roles come from lists, so the free-text surface shrinks to just Notes.
🚦 Auto-moderation on Notes — wordlist filter + a cheap classifier flag hate/spam before publish.
⏱️ Rate limits — a few edits/hour per identity stops flooding.
🚩 Report button — anything that slips through gets flagged to a small review queue.

Never a hard lock. A disputed credit shows a public ⚑ contested state and resolves on cheap signals — work-email domain match, peer vouches for the real person, public 1-click-reversible edit history, one active claim per credit. You mostly don't referee it.
Because the catalog has no messaging, a bad claim just means "a credit is briefly wrong" — low stakes. That changes only if you ever add the contact/network layer, which stays out of scope here.
Longevity promise (built in): public data dumps + per-user export, dataset openly licensed (e.g. CC-BY). If DevQuest ever shuts down, the credits people invested can be mirrored or handed to a steward — they don't die with the site. MobyGames only survives via ownership hand-offs (Atari bought it in 2022); open data is the durable version of that.
