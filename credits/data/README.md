# credits/data - the credits dataset

This folder holds the data behind the credits catalogue. There are two kinds of data from two sources.

## 1. Games + studios catalogue (automated, Wikidata)
- Files (planned): `games.json`, `studios.json`
- Source: **Wikidata (CC0)**, pulled by a scheduled cloud job (a GitHub Action, same pattern as the jobs scraper; never a runtime call).
- Contents: comprehensive games (title, studio, year, platforms, genre, wikidata_qid) and studios, plus any notable individual credits Wikidata happens to have.
- Do not hand-edit; it is regenerated by the pull.

## 2. Seed credits (hand-entered / first-party)
- File: `seed-credits.json`
- Source: primary and freely-licensed sources only (in-game credits, official press kits, studio websites, Wikipedia) and first-party contributions (you and the beta network entering your own games). See spec Section 15 for what is and is not a clean source.
- Merged with the games catalogue by `slug`.

## Schema (`seed-credits.json`)
Each game object:
- `slug` (kebab-case, unique key that matches the catalogue)
- `title`, `studio`, `year`, `platforms` (array), `genre`
- `wikidata_qid` (optional; links to the catalogue entry)
- `source`: "hand" | "wikidata"
- `credits`: array of:
  - `name` (person as credited)
  - `role` (primary/headline title, e.g. "Content Lead" — the one shown everywhere)
  - `roles_other` (optional array of other titles held on the same game, e.g. `["Technical Support Lead", "Game Designer", "Content Manager"]`; shown as a "+N more" affordance)
  - `attribution`: "credited" | "special_thanks" | "uncredited" (how the game credits them; see spec 4 and 5.3)
  - `verification`: array of signals: "in_game_credits" | "studio_website" | "press_kit" | "linkedin_self" | "peer_vouch" | "community" (see spec 15)
  - `source_url`: where the fact came from (provenance; required)
  - `note`: optional

## Rules
- **Provenance is required.** Every credit needs a `source_url` or a note saying where it came from.
- **Clean sources only.** Primary/free sources and first-party contributions. Never systematic extraction from MobyGames, GameFAQs, or Giant Bomb, and never LinkedIn crawling (spec Section 15).
- **Facts, not prose.** Record the factual credit (person, role, game), not copied descriptive text.
