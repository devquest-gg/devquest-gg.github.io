UI Tools Programmer

Rockstar Games · Dundee

Mid Engineering Onsite Posted 2025-03-07 Full time

At Rockstar Games, we create world-class entertainment experiences.

Become part of a team working on some of the most rewarding, large-scale creative projects to be found in any entertainment medium - all within an inclusive, highly-motivated environment where you can learn and collaborate with some of the most talented people in the industry.

Rockstar Dundee is on the lookout for a passionate UI Tools Programmer to deliver world class user interfaces that help form the connection between the player and our games.

This is a full-time, permanent and in-office position based in Rockstar’s unique game development studio in the heart of Dundee, Scotland.

WHAT WE DO

The Rockstar Games UI Team is a diverse, multinational team made up of programmers and developers from across our studios.

We work together across time zones to use our industry-leading, in-house proprietary “RAGE” engine to produce the User Interface features that form the connection between the player and our games.

We develop our own UI tools, editors and technologies to let our UI developers realize the creative vision of the projects we work on while constantly striving for excellence to produce the seamless UI experience our millions of players expect.

RESPONSIBILITIES

Develop new tools and improve existing ones for efficient UI content creation.

Collaborate with your lead, and have ownership of tool feature deliverables and sets of tasks to assist other tool feature areas.

Work with the other UI tool team members and review other programmer’s code and ensure your feedback helps to meet the expected quality levels.

REQUIREMENTS

A degree in software engineering, mathematics or computer science.

2+ years professional programming experience.

Adept in C# and high-level design patterns.

Comfortable with a wide range of code architectures including OOP design patterns, MVVM and SOLID programming.

Familiarity with MVVM software design. Especially WPF.

Experienced with the programming challenges related to UI development.

Strong debugging and deductive skills.

PLUSES

Please note that these are desirable skills and are not required to apply for the position.

In-depth familiarity with Rockstar products.

Ideally 1+ published console title or 2+ years game development experience.

Developed and delivered high level software tools to internal clients, such as a game editor application for peers.

Adept at C++, can understand proprietary open-source C++ library usage.
