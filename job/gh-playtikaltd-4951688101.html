The Role

You ll join our QA engineer as the second set of hands covering quality for the studio. Day to day, you ll split your time between manual testing, building out test automation, and helping keep the live game running smoothly - using AI tools to work faster and smarter.

Responsibilities:

Manual QA

Test new features, builds, and game mechanics across platforms (iOS / Android / Web)

Design and execute test plans, exploratory testing, and regression passes before releases

Write clear, reproducible bug reports and track them to resolution

Validate fixes and sign off on release candidates

Automation QA

Build and maintain automated test suites (UI, API, regression) to reduce manual overhead

Integrate automated tests into our CI/CD pipeline

Continuously identify what should be automated next as the game grows

Use AI-assisted tools to speed up test case generation, script writing, and bug triage

Operations

Monitor live game health: dashboards, KPIs, crash reports, error rates

Be a first responder on production issues — triage, escalate, and help coordinate fixes

Support live-ops activities: config pushes, event setups, app store submissions, release coordination

Help keep internal processes (release checklists, monitoring alerts, documentation) lean but solid

Requirements:

4+ years of QA experience, ideally in mobile gaming or another fast-shipping consumer product

Hands-on experience with test automation frameworks (e.g., Appium, Selenium, Playwright, or similar)

Comfortable scripting (Python, JavaScript, or similar) to build and maintain automated tests

Familiarity with CI/CD pipelines and bug tracking tools (Jira or similar)

Genuine comfort using AI tools (Claude, ChatGPT, Copilot, etc.) as part of your daily workflow — this isn t optional flavor text, it s how we work

An "ops" mindset: comfortable monitoring live systems, digging into data, and handling things outside a strict QA job description when needed

Startup DNA: self-driven, low ego, comfortable with ambiguity, happy to build process rather than wait for it

Nice to Have

Experience with casual, or social casino games specifically

Experience with live-ops tooling, remote config, or A/B testing platforms

Comfortable reading and interpreting data/dashboards to spot issues - you should understand what the numbers are telling you, with AI tools handling the heavier data-pulling or data-querying

Experience in a small studio or startup environment (not just large studio QA teams)
