What We Need

We are seeking a Build Systems Engineer with experience running production game development pipelines in the cloud to migrate, support, and optimize standardized build environments across both Unreal Engine’s Horde and Jenkins. In this role, you will help ensure the reliability, scalability, and efficiency of our build pipelines by automating workflows, managing continuous integration pipelines, and monitoring system performance. A primary objective will be leading and supporting the migration of existing build pipelines to cloud infrastructure, directly focusing on maximizing service uptime and delivering measurable performance improvements over our legacy on-premise instances.

The ideal candidate will bring strong technical expertise, a proactive problem-solving mindset, and hands-on experience troubleshooting complex build environments across diverse technology stacks. You will collaborate closely with developers, platform engineers, and DevOps/TechOps teams to streamline game production workflows, deploy standardized build configurations across multiple studios, and implement robust observability solutions. By balancing day-to-day operational support with long-term infrastructure improvements, you will create reusable automation, maintain technical documentation, and help drive continuous integration best practices across our entire development ecosystem.

Duties

Guide the migration of studio build pipelines to cloud environments, ensuring cloud services meet or exceed the reliability and performance of existing on-premise instances.

Maintain and optimize existing build systems, focusing on both Unreal Horde and Jenkins for operational performance and stability.

Contribute to standardization across Horde and Jenkins deployments while accommodating the functional requirements of diverse game teams.

Develop build automation scripts and maintain reusable pipeline components.

Assist in integrating related services, plugins, and automation tools into CI/CD workflows.

Support observability solutions to monitor build ecosystems and track cloud service performance metrics.

Create clear documentation and promote build automation and CI/CD best practices across teams.

Collaborate with Perforce specialists to ensure reliable source control integration.

Provide technical support, guidance, and troubleshooting assistance to internal development and build teams.

Must-Haves

Practical experience running and maintaining Production level build systems supporting game development pipelines.

Hands-on experience migrating existing build pipelines to cloud infrastructure (AWS, Azure, or GCP) with a track record of maintaining high uptime and performance.

Hands-on experience applying CI/CD, Agile, and DevOps methodologies within software or game development pipelines.

Proficiency in scripting and automation using languages such as Python, C#, or similar.

Working knowledge of Infrastructure as Code tools (Terraform, Ansible) to manage compute capacity and cloud infrastructure.

Familiarity with configuration management tools (such as Puppet) for maintaining existing build machines and services.

Solid OS troubleshooting skills across both Windows and Linux environments.

Strong problem-solving ability to isolate and resolve build pipeline failures quickly.

Clear communication and collaborative skills when working cross-functionally with engineers, studios, and external stakeholders.

Commitment to good documentation habits and continuous learning in CI/CD and cloud technology space.
