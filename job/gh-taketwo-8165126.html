What You’ll Take On

Work with the data governance and business teams to develop and support solutions built using Informatica’s MDM platforms (Product 360, Reference 360, Code Java, ActiveVOS, Python-based backend processes for custom reporting).

Solution Design Configuration: Design and configure the Informatica MDM platforms, including Data Models, Mappings, Validation Rules, etc.

Build and configure technical components (interfaces, conversions, reports, workflows) ensuring solution design meets business needs and solution architecture standards.

Create development artifacts including but not limited to data models, data profiles, technical specification documentation.

Perform data quality testing for the purpose of ensuring compliance with established data quality standards and attributes, including business logic testing, integration testing, remediation testing, and other testing as needed

What You Bring

5+ years of relevant hands-on experience of end-to-end implementation of one or more Informatica MDM platforms (Product 360, Reference 360) including core MDM functions and data integrations across batch and near-real time interfaces.

3+ years of advanced SQL skills and fundamental knowledge on python coding to enhance backend processes.

Hands-on experience of setting up repositories, users, and security management.

Hands-on experience with Active-VOS BPM workflows (REST-based and Message Queue-based) and ability to convert one kind to another following Informatica standard practices.

Strong foundation in Basic Java and Step Workflows for efficient migration of AVOS workflows.

Experience in PIM installation, hotfix upgrades, and basic SDK-based customization.

Ability to create simple Data Quality (DQ) rules using IDQ/CDQ platforms.

Experience in CAI guides/process development and complex task flows for Ref360 building Ref360 processes is a plus.

Experience with Informatica Intelligent Data Management Cloud (IDMC) is highly desirable.

Strong problem-solving skills with a keen eye for troubleshooting data anomalies and tracing integration logic flaws.

Excellent verbal and written skills to clearly explain highly technical data structures to non-technical business partners.

Bachelor’s degree or equivalent in an engineering or technical field such as Computer Science, Information Systems, Statistics, Engineering, or similar.
