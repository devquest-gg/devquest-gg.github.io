Senior Engine Programmer - OS (Game Network)

Ubisoft Montreal · Montreal

Senior Engineering Posted 2026-10-07 Full time
Apply on Ubisoft Montreal’s site →

As a Senior C++ Engine Programmer at Ubisoft Montréal, you’ll join the Core Services - Online Tech Foundations team. The team builds technology that supports online services across many Ubisoft productions. You’ll help design and evolve distributed systems and middleware used in games, including game engine, low-level, networking, and engine-integrated web components.

What you’ll do Develop and improve reliable, high-performing, maintainable C++ middleware.

Contribute to technical direction and architecture choices.

Improve code quality through good practices, code reviews, and continuous improvement.

Solve complex technical problems and optimize performance.

Reduce risks and technical debt to help keep solutions sustainable.

Collaborate with teams and other stakeholders.

Share knowledge and keep up with technical developments.

What you bring to the team Apply modern C++, including C++17, C++20, and C++23.

Design software architecture, efficient algorithms, and optimized data structures for complex systems.

Optimize memory management, multithreading, and processor use.

Use debugging, profiling, continuous integration, and continuous deployment to maintain code quality.

Solve complex problems, communicate clearly, work with others, and contribute to technical choices.

Bring, as an asset, experience with console development or multiplayer game projects.

Bring, as an asset, knowledge of C#, .NET, Visual Studio, CMake, LLVM tools, GitLab-CI, or agile methods.

Bring, as an asset, knowledge of game engines such as Snowdrop, Anvil, Unreal, or Unity, cloud services such as AWS or Azure, distributed systems, or network optimization.
