关于 VOODOO

Voodoo 成立于2013年，总部位于法国巴黎，是一家以“用娱乐点亮世界”为使命的全球领先娱乐科技公司。我们通过打造标志性的手机游戏和应用，持续影响全球数亿用户的日常娱乐体验。目前公司在全球范围内拥有约1000名员工，年收入近8亿美元。公司旗下拥有Paper.io http://公司旗下拥有Paper.io、Mob Control、Hole.io http://Hole.io、Marble Sort、Castle Buster等经典爆款游戏，以及BeReal、Wizz等热门社交应用。累计下载量已突破80亿次，每月活跃用户超过2亿，是全球下载量排名第三的移动发行商（仅次于Google和Meta）。

工作地点：北京（成都可协商），需全职到岗办公。

团队介绍

Voodoo 游戏团队汇聚了混合休闲、休闲和中重度游戏领域的专家。其中，“Core ”游戏团队与全球内部及外部工作室合作，创造、开发并发行新的爆款游戏；“Live” 游戏团队则专注于提升现有成功产品的长线运营。

我们正在国内组建一支全新的内容研发团队，负责 Voodoo 正在运营中的爆款休闲益智游戏 Marble Sort。团队小而精，由主策划、关卡策划、资深 Unity 开发和 3D 美术组成，并与 Voodoo 欧洲成熟的 Marble Sort 项目团队紧密协作，共享代码、工具和经验。团队将从新障碍物和新关卡做起，随着团队成长，逐步承担长线运营内容和关卡类活动的研发，目标是发展成为一个独立的内部工作室。

岗位职责

作为游戏开发工程师，你将在游戏现有的 Unity 代码基础上，开发新的解谜机制、障碍物和工具，支撑数百万玩家每天挑战的关卡。

1. 使用 Unity 和 C# 实现新的解谜机制和障碍物；

2. 开发关卡编辑器及内容工具，帮助关卡策划更高效地制作和测试关卡；

3. 配合关卡策划和产品团队，支持关卡迭代与难度调优；

4. 负责美术资源、特效和动画的接入，打磨游戏手感与操作反馈，让玩家的每一步操作都有满足感；

5. 负责多机型适配与性能优化，保证游戏在各类移动设备上稳定、流畅运行；

6. 逐步参与新功能、运营活动和新玩法模式的开发。

任职要求

1. 本科及以上学历，5年以上Unity开发经验。

2. 有扎实的 Unity 和 C# 开发经验，参与过已上线的手游项目；有休闲或益智类游戏（如三消、排序、合成类等）开发经验者优先；

3. 有在线上运营项目的既有代码基础上开发新功能或新内容的经验；

4. 熟悉 Unity 玩法系统、UI、动画及手感打磨，重视移动端性能与内存优化；

5. 有为策划开发工具（如关卡编辑器、内容生产工具）经验者优先；

6. 有良好的团队协作精神，乐于接受反馈，能适应快速迭代；

7. 英语加分但非必需，可全程中文面试。
