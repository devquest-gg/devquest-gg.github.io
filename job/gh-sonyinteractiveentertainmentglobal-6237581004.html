Storage Software Developer

We are seeking a Storage Software Developer with Linux storage development experience. You will build reliable, high-performance storage features across the I/O stack, including file systems and the block layer. Depending on the project, your work may span Linux, FreeBSD, and PlayStation OS. You will collaborate with systems and kernel engineers to investigate problems, make design decisions, and bring solutions into production.

Key Responsibilities

- Design, implement, and maintain storage features and I/O paths for Linux and, as projects require, FreeBSD and PlayStation OS. - Develop or improve file system functionality, including how it interacts with the block layer. - Diagnose correctness, reliability, and performance issues across kernel and user-space components. - Measure and optimize storage performance for demanding workloads. - Write maintainable code, tests, and technical documentation. - Collaborate with engineers across storage and other systems teams.

Required Qualifications

- Hands-on experience developing storage software on Linux. - Some experience developing or modifying Linux file system code. - Working knowledge of the Linux I/O stack, including file systems and the block layer. - Proficiency in C for systems programming. - Experience debugging and profiling low-level software using tools such as perf, ftrace, or eBPF. - Ability to investigate complex problems and work effectively with other engineers. - Willingness to work across Linux, FreeBSD, and PlayStation OS as project needs evolve.

Preferred Qualifications

- Experience with **UBLK** and kernel/user-space block device interactions. - Experience developing storage or file system software on FreeBSD or PlayStation OS. - Experience with **io_uring** or other asynchronous I/O interfaces. - Familiarity with DMA and storage performance optimization. - Experience with Rust for systems programming. - Contributions to the Linux kernel or other open-source storage projects.
