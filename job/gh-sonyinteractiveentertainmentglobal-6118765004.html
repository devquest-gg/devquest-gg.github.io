The role

We are looking for a Software Engineer to join the Kit Manager team, working on the design and development of a scalable private cloud solution for managing PlayStation Development Kits along with the provision of associated APIs and services as part of the PlayStation® SDK.

What you’ll be doing

Own the end-to-end delivery of features, from requirements analysis and design through implementation and validation

Investigate, debug, and resolve issues in existing code and newly developed featuresParticipate in requirements gathering and architectural discussions, collaborating with cross-functional teams in an agile environment

Participate in code reviews and contribute to maintaining high engineering standards

Attend periodic in-person workshops and team events, with occasional travel as required

What we’re looking for

You should bring some of the following skills and experience:

Excellent problem-solving and analytical skills

A passion for building intuitive products with a strong focus on user experience and developer workflows

Commercial or open-source experience developing software in Rust, with the ability to design, implement, and maintain production-quality code, and a strong understanding of Rust fundamentals including ownership, borrowing, lifetimes, traits, generics, error handling, and asynchronous programming with Tokio

Strong commercial experience developing software in modern C++

A solid understanding of concurrency, multithreaded programming, and modern software design principles

Experience writing automated tests and applying modern software testing practices

Proficiency with Git or other distributed version control systems

Desirable skills and experience

Experience developing cross-platform applications for Windows, Linux, and macOS

Experience with PostgreSQL or other relational databases

Experience building APIs using gRPC and/or REST

Experience deploying and managing applications using Kubernetes and/or AWS

Proficiency with Docker, Podman or other container technologies

Experience developing user interfaces with React

Qualifications

BSc /MSc in Computer Science or equivalent experience
