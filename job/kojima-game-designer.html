Map design Adjusting the alignment of enemies and items to be placed on a map, etc.

Building missions and events using visual scripts Adjusting various parameters Requirements Native level Japanese language proficiency (JLPT N1 required) Experience in developing one or more game titles as a game designer or level designer Those who can think logically and communicate properly (mutual understanding).
