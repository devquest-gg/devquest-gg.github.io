Senior Software Engineer Cloud Engineering (Contractor)

We are seeking a Senior Software Engineer to be part of a new engineering team supporting our Cloud Streaming platforms. This individual will partner closely with existing domain experts, develop deep expertise in complex distributed systems, and serve as the technical foundation for building a new high-performing team.

What You’ll Do

Design and implementation of features in distributed back end systems

Ownership of the implementation and delivery of well-defined features from start to finish

Implementation of unit tests via testing frameworks

Define and craft integration tests with Test Engineering

Solve performance and reliability issues at a global scale

Triage and fix reported bugs

Communicate estimates, schedules, issues, and dependencies to technical or project lead

Requirements

BS in Computer Science (or equivalent experience)

5+ years of relevant experience

In-depth experience in Java

Experience with AWS technologies and managed services

Knowledge of Kubernetes, Docker, Helm

Development experience with Linux

Intermediate knowledge of version control tools such as git, Github and GitLab

Familiarity with CI/CD pipelines, ArgoCD

Knowledge in NoSQL, Prometheus, Elasticsearch, and other CNCF technologies

Deep understanding of distributed systems, storage architectures (object/block), networking, and high-availability design

Understanding of concepts such as concurrency, parallelism, and event driven architecture

Knowledge of Web technologies including REST and gRPC

Strong communication and documentation skills

Nice to Have

Experience with Python or Rust a plus

Familiar with Agile development concepts

Experience with streaming platforms, cloud gaming, or large-scale distributed systems

Infrastructure-as-code experience (CDK, Terraform)

Familiarity with AI-assisted development tools and modern cloud-native practices
