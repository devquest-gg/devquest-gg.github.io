Sr. Software Development Engineer in Test

Austin, TX

Role Overview

Sony Interactive Entertainment LLC seeks a Sr. Software Development Engineer in Test in Austin, TX to collaborate with QA and Devs teams to ensure high-quality for web applications and content delivery platform.

Requirements

Master’s degree in Management Information Systems, Computer Science, or related field or equivalent and two (2) years of experience supporting quality assurance and test automation for digital content delivery platforms and applications, including end-to-end content workflows and validation of CDN-backed delivery systems; designing, developing, and maintaining automated test frameworks and test suites for complex web applications with modular and micro–front-end user interfaces and service-oriented architectures; utilizing Java object-oriented programming principles and data structures, including collections, generics, lambdas, and concurrency concepts with multi-threaded test execution to develop and maintain automated tests frameworks using Spring Boot and Maven; implementing UI and API automation using Selenium WebDriver, TestNG and JUnit, and Rest-Assured for RESTful service testing, including DTO-based JSON/XML validation and SQL-based database validation; integrating CI/CD pipelines and automation using Jenkins with Groovy and shell scripting; utilizing JaCoCo and SonarQube within GitHub-based workflows to support quality-driven releases; supporting performance, reliability, and scalability testing using Apache JMeter and applying shift-left testing; testing cloud-native and distributed systems in AWS-based environments supporting event-driven architectures, including SNS and SQS, indexing and search capabilities (Elasticsearch); leveraging AWS SDKs to verify cloud services in Docker and Kubernetes environments, while monitoring via Datadog and CloudWatch; and performing in agile ceremonies, peer code reviews, post release validations, defect triage and root cause analysis sessions. Telecommuting and/or working from home may be permissible pursuant to company policies.
