Senior UI Programmer

Highdive is seeking a seasoned generalist programmer that can support UI/UX team to build and optimize game interfaces, implement menus, HUD, and UI tools across platforms, collaborating with designers and artists to ensure cohesive visuals and performance.

Responsibilities

Develop and oversee game presentation modules (menus, HUD) and underlying UI systems.

Analyze game design documents, actively challenging design and UX to optimize the intended player experience.

Design, prototype, and implement UI/menu systems across platforms, ensuring visual and logistical uniformity.

Integrate designs and animations; provide technical hooks for graphics, animation, and audio.

Identify and resolve technical limitations, optimizing UI code for strict performance and memory constraints.

Apply structural knowledge of ergonomics, UX principles, localization, and accessibility.

Iterate rapidly based on inter-departmental feedback.

Maintain industry knowledge regarding UI frameworks and innovations.

Use AI/LLM tools to increase productivity.

Qualifications

Bachelor s degree in Computer Science, Computer Engineering, or equivalent.

Minimum 6 years of C++ programming experience in game development or embedded systems.

Capacity to write clean, maintainable, and performant C++ code, applying software engineering best practices (design/code reviews, testing, documentation).

Understanding of MVVM philosophy and workflows.

Exceptional troubleshooting and debugging capabilities.

Strong communication skills for multi-disciplinary collaboration.

Experience with Unreal Engine 5 (Slate, UMG)

Bonus: CommonUI, and Unreal’s MVVM plugin, PC-centric platform workflow experience.
