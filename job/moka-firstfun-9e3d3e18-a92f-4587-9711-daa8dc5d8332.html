Client Engineer - Early Career

FirstFun

Mid Engineering Posted 2026-10-06 Full time
Apply on FirstFun’s site →

Key Responsibiltiies: Participate in the design, development, testing, release, and maintenance of mobile game client features, completing development tasks on schedule with guidance from the team.

Implement client features based on gameplay and product requirements, including basic gameplay logic, UI interactions, character presentation, and player feedback.

Assist with integrating server APIs, remote configuration, and analytics reporting, and work with server engineers, game designers, and QA on feature integration testing.

Follow team coding standards, write clear and maintainable code, and participate in code reviews and bug fixes.

Participate in client testing and performance checks, helping diagnose issues related to startup, loading, frame rate, memory, and device compatibility.

Collaborate with game designers, artists, server engineers, and QA, communicating promptly about your understanding of requirements, progress, and technical issues.

Proactively learn about game engines, mobile development workflows, and AI-assisted tools to improve development efficiency while maintaining code quality.

Requirements Bachelor’s degree or higher in Computer Science, Software Engineering, Information Technology, or a related discipline. This role is intended for fresh graduates.

Strong programming fundamentals, familiarity with at least one of C# or TypeScript, and an understanding of data structures, algorithms, and object-oriented programming.

Familiarity with Unity, Unreal, or another game engine; coursework, personal project, or internship experience is preferred.

Understanding of operating system, computer network, and database fundamentals, with the ability to use debugging tools to diagnose common programming issues.

An interest in game development and a willingness to learn about gameplay systems, UI, asset management, and mobile performance optimization.

Strong communication, collaboration, analytical, and problem-solving skills, with the ability to clearly explain your progress and any difficulties encountered.

Preferred Qualifications Experience with Unity or Unreal game projects, game development competitions, or client projects you can showcase.

Experience with Android or iOS development, device compatibility, performance profiling, or automated testing.

Experience using coding assistants, automated testing tools, or other AI development tools, with the ability to assess and verify generated outputs.

Why Join Us You will contribute to client development for real mobile games, working with game designers, artists, server engineers, and QA to turn gameplay ideas into playable features while progressively building your engineering skills through hands-on project experience.
