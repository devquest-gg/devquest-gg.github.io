About the role

Wordscapes serves millions of monthly players across iOS and Android. Every update, every A/B test, and every new feature ships to a massive live audience. We need someone who can build the testing infrastructure that lets us move fast without breaking things, with AI tooling as a core part of how that work gets done.

This is a hybrid role. Half of it is building: you’ll take our on-device test automation from prototype to a production framework and scale it to real coverage of our weekly releases. The other half is leading: you’ll run one of our QA pods, a group of testers aligned to a feature area, and own test planning, tester direction, and release sign-off for that area. You’ll partner with gameplay engineers, product managers, and the other pod leads, and scale AI-assisted workflows across our release process.

Current state: Our automation stack is selected and proven out in early prototypes, but there isn’t a full framework yet. You’ll grow it toward release testing that’s automated from build verification through regression and release candidate sign-off.

What you’ll do

AI-Driven Quality Engineering

AI tools are already part of how we test: generating test scaffolding, finding edge cases, and speeding up failure diagnostics. You’ll:

Use AI tools daily to write, maintain, and debug automated tests faster

Build repeatable AI-assisted workflows, such as turning manual test cases into automation scripts and running agent-driven exploratory passes

Drive AI adoption across the QA team, setting the practices and standards others follow

Treat this as how you work across everything below, not as a separate workstream

Build Scale Test Automation

Take our selected automation stack from prototype to production: design the framework architecture, set its standards, and make it easy for others to extend

Develop and maintain automated tests within Unity using C#, including PlayMode and EditMode tests for gameplay systems, economy logic, and progression flows

Stand up automated test runs on physical iOS and Android devices, starting with the core gameplay loop and the highest-volume rote regression checks

Turn manual test suites into automated coverage, and set the conventions for how new test cases get scripted

Create in-engine tools to simulate player states and feature/A/B test configurations for faster validation

Use APIs, telemetry, and logs as verification signals within on-device tests

Partner with gameplay engineers to embed test hooks directly into systems as they’re built, shifting quality upstream

Pod Leadership

Lead a QA pod: write and own its test plans and test suites for features, A/B tests, and releases

Direct and prioritize your testers’ day-to-day work, including external test partners

Triage and track defects in Jira and drive them to resolution with engineering and product

Own release sign-off for your pod’s area and make clear go/no-go calls

Work with the other pod leads and the QA Manager on shared QA process and staffing

Tooling, Process Mentorship

Build internal QA tools that reduce manual testing burden and improve release quality gates

Improve test reliability and reduce flakiness across the suite

Mentor QA team members in automation fundamentals. This is a meaningful part of the role, not an afterthought. You’ll help level up the team’s technical capabilities over time
