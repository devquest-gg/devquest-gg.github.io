Technical UI Designer

HyperHug · Remote · Remote

Mid Design Remote Posted 2026-08-03 Full time
Apply on HyperHug’s site →

HyperHug is an international game development studio specializing in the shooter genre. Our main office is based in Cyprus, but our talented team works remotely from around the world. We’re developing Oxide: Survival Island, an immersive multiplayer survival shooter for mobile platforms, and we’re always looking for motivated individuals who want to grow with us, contribute their creativity, and help shape the future of our games.

We’re looking for a skilled Middle+/Senior Technical UI Designer to bring polished, intuitive game interfaces to life. You’ll turn design concepts and mockups into responsive, production-ready UI, creating scalable systems that look great, perform smoothly on mobile devices, and are easy for the development team to integrate and maintain.

WHAT YOU’LL BE DOING:

- Implement core and meta-game interfaces in Unity.

- Build responsive screens that adapt correctly to different resolutions and aspect ratios.

- Create and maintain a scalable UI architecture, including window structures, reusable components, UI kits, and prefabs.

- Create UI animations using DOTween, Timeline, and custom animation solutions.

- Set up and optimize UI effects using Unity’s Particle System.

- Optimize UI performance for mobile devices, including draw calls, batching, and Canvas setup.

- Work with text styles, materials, and localization.

- Optimize textures, atlases, and import settings.

- Create UI materials using Shader Graph and custom material setups.

- Refactor, simplify, and systematize legacy UI.

- Create and maintain UI documentation.

- Write simple C# scripts when needed.

WHAT WE EXPECT FROM YOU:

- 3+ years of experience in a similar role.

- Strong experience using AI tools to improve day-to-day workflows, create and integrate reusable UI components and event systems.

- Strong hands-on expertise with Unity UI.

- Solid understanding of UI performance optimization, especially for mobile devices.

- Ability to work independently and propose practical solutions.

- Strong attention to detail and a structured, systematic approach to work.

- English - B1+ level, Russian - C1 level.

WHAT WE OFFER:

- Competitive salary.

- Remote work format.

- A passionate and supportive team that values creativity and ownership.

- Opportunities for professional growth.

- A culture built on initiative, transparency, and collaboration.
