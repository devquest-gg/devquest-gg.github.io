Senior UI Artist

We are looking for a Senior UI Artist to join our team on a AAA single-player project. This role is ideal for a creative artist who is equally comfortable crafting polished visual interfaces and implementing them directly in Unreal Engine.

The ideal candidate combines strong artistic sensibilities with solid technical expertise, allowing them to bridge the gap between design, art, and engineering. You will be responsible for creating high-quality user interface assets, implementing them in Unreal Engine, developing custom UI materials, and collaborating closely with UI programmers to deliver an exceptional player experience.

Reporting to the UI Lead, you will work as part of a small multidisciplinary team to define, improve and implement the visual language of the game s interface.

Responsibilities

Create high-quality UI assets, including HUDs, menus, widgets, icons, and supporting graphic elements.

Translate wireframes, UX flows, and visual concepts into polished in-game interfaces.

Implement UI screens and features directly in Unreal Engine using UMG.

Develop and maintain custom UI materials and shaders to support advanced visual effects and animations.

Collaborate with UI programmers to ensure scalable, efficient, and maintainable implementations.

Create and iterate on motion graphics, transitions, and animated UI elements.

Contribute to improving visual quality standards across the project.

Support localization requirements and ensure UI layouts adapt correctly across multiple languages.

Optimize UI assets, materials, and implementation for performance and memory constraints.

Participate in feature reviews, feedback sessions, and cross-disciplinary problem solving.

Required Qualifications

Shipped at least one PC or console title as a UI Artist.

Strong portfolio demonstrating high-quality UI work for games, specially a stylized game.

Extensive experience with Unreal Engine and UI implementation workflows.

Advanced knowledge of UMG.

Strong understanding of custom UI materials, shaders, and dynamic visual effects within Unreal Engine.

Experience integrating UI assets and visual behaviors directly into game-ready implementations.

Solid understanding of Blueprint-driven UI workflows and collaboration with gameplay and UI programmers.

Excellent graphic design fundamentals, including typography, hierarchy, composition, color, and visual communication.

Proficiency with:

Adobe Photoshop

Experience creating and exporting production-ready UI assets for game development.

What Success Looks Like

Develops robust and reusable UI materials and effects within Unreal Engine.

Works effectively with UI lead and programmers to transform designs into polished gameplay experiences.

Maintains consistency across all player-facing UI systems.

Balances artistic sensibility with implementation efficiency and technical requirements.

Support, as a key contributor, both the visual and technical direction of the UI team.

Candidate Profile

The ideal candidate is a 50/50 blend of artist and technical implementer. They possess strong visual design skills and are equally comfortable opening Unreal Engine to build, troubleshoot, and refine their own work. They understand how UI assets move from concept to implementation and have the technical confidence to create custom UI materials, work within UMG, and collaborate closely with engineers to ship high-quality game experiences.
