NetEase is a globally renowned game developer and publisher. As a core business unit under NetEase, the Game Application and Platform Development Group consistently explores new opportunities and technological innovations across the gaming ecosystem and the broader internet industry. Responsibilities：

Develop and iterate on features for our Android productivity applications, completing module-level development tasks under guidance from senior engineers

Learn and implement the modern Android development tech stack including Kotlin, Jetpack components and Jetpack Compose

Gradually take full ownership of independent feature modules and deliver end-to-end feature implementation

Participate in code reviews, technical seminars and the implementation of team engineering best practices

Cooperate with product managers and UI/UX designers to sort out user requirements, clarify development demands and convert business needs into feasible technical solutions

Monitor application runtime performance and stability; assist in troubleshooting and resolving online production failures

Write clean, maintainable and fully tested code complying with unified team coding specifications

Requirements:

Bachelor s degree or higher, expected graduation in 2027

Solid computer science fundamentals; proficient in data structures, algorithms, operating systems and computer network principles

Skilled in at least one object-oriented programming language such as Java, Kotlin or C++

Basic Android development capabilities: familiar with Activity Fragment lifecycle, Android core application components, mainstream UI components and basic event handling mechanisms

Hands-on project experience including academic course projects, open-source contribution or internship experience; project thinking process and technical growth are valued far more than project scale

Excellent problem-solving capability and self-directed learning skills; able to master new technologies through official documents, open-source projects and official Android demo cases

Clear logical expression, excellent cross-team collaboration awareness, strong work ownership, and willingness to tackle difficult technical challenges

Able to conduct daily workplace communication in Mandarin, with basic English reading and writing proficiency

Preferred Qualifications:

Previous Android development internship experience, or independent development of usable Android applications or functional prototypes

Familiar with Kotlin language features, coroutines and basic asynchronous development based on Flow

Basic cognition of Android performance optimization, memory optimization and UI rendering optimization

Experience in algorithm competitions, technical blog output or GitHub open-source project development and maintenance

Familiar with or keen interest in the overseas Android product ecosystem including Google Play and Material Design specification
