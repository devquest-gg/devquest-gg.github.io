Position - Technical Design Intern We are looking for a Technical Design Intern to join the Haven Interactive Studios project team. The Technical Designer works as a bridge between game design, level design, and programming. Part of the features and systems validation process, you will anticipate and support the game modes team.

You will work with the Technical Level Design Director in order to establish clear guidelines and rational level design rules for best usage of our features and systems in game. You will also coordinate, create and maintain effective in-game tools and debug tools for designers.

Reporting The Technical Designer will report to a producer.

Responsibilities and Duties Develop and maintain in-game tools and debug tools for designers.

Work closely with the programming team to enhance existing tools and create new ones.

In parallel with the features and systems development, build a solid rational level design checklist and communicate technical requirements to the level design team to ensure the best in-game experience.

Act as a bridge between the design team and the engineering team to ensure the tools and engine developments support the game design needs.

Implement data validation strategies (reports, automated testing, etc.) Optimization for systems and features.

Clean up outdated data and error logs Experience and skills required Currently enrolled in University/College with programming, game design or technical design focus Scripting or programming experience Relevant internship experience is an advantage.
