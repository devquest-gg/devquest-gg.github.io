Software Engineer II, Java Madison, WI

Platform Engineering / PlayStation Network PlayStation is looking for a Software Engineer with strong Java experience to help build and operate scalable backend services that power the PlayStation ecosystem. You will work on systems that support PlayStation Network, digital commerce, subscriptions, gaming services, media experiences, partner integrations, and internal platforms used across Sony Interactive Entertainment.

This role focuses on designing, developing, testing, deploying, and maintaining modern Java-based services in a cloud-native environment. You will collaborate with engineers, product managers, designers, QA, security, operations, and business partners to deliver reliable services used by millions of players across PlayStation consoles, web, mobile, PC, and connected devices.

Responsibilities

Design, develop, test, and maintain backend services using Java and modern frameworks such as Spring Boot.

Build and enhance APIs, microservices, and platform components that support PlayStation Network and related digital services.

Collaborate with cross-functional teams to deliver features for commerce, subscriptions, identity, content, gaming, media, or partner integrations.

Write clean, secure, maintainable, and well-tested code.

Develop and maintain RESTful APIs and event-driven services.

Create and execute unit, integration, and automated tests using tools such as JUnit, Mockito, Test containers, or similar frameworks.

Work with relational and NoSQL databases, including writing efficient queries and understanding schema design.

Participate in code reviews, design discussions, sprint planning, and technical documentation.

Debug, troubleshoot, and resolve production and pre-production issues.

Contribute to CI/CD pipelines and deployment automation.

Support cloud-native applications running in environments such as AWS, containers, and Kubernetes-based platforms.

Use monitoring, logging, tracing, and alerting tools to improve service reliability and

Help refactor legacy systems and migrate services toward modern architectures where appropriate.

Follow secure development practices, including data protection, authentication, authorization, and dependency management.

Communicate technical status, risks, dependencies, and tradeoffs clearly to teammates and stakeholders.

Continuously improve engineering standards, development workflows, and operational practices.

4+ years of professional software development experience with Java-based backend systems.

Experience building backend applications or services using Spring Boot, Spring MVC, or related Java frameworks.

Experience designing and consuming RESTful APIs.

Ability to write SQL queries and understand database performance considerations.

Understanding of Agile/Scrum software development practices.

Strong problem-solving skills and ability to work independently with guidance.

Excellent communication skills with both technical and non-technical partners.

Bachelor’s degree in Computer Science, Engineering, a related technical field, or equivalent practical experience.
