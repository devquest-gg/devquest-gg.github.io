About Atari

Atari is an interactive entertainment company and an iconic gaming industry brand recognized worldwide for its multi-platform games and licensed products. Atari owns and/or manages a portfolio of more than 400 games and franchises, including globally recognized brands such as Asteroids® , Centipede® , Missile Command® , Pong® , and RollerCoaster Tycoon® .

The Atari family of brands includes Digital Eclipse, Nightdive Studios, Infogrames, AtariAge, MobyGames, as well as Coatsink, Early Morning Studios, and Stormteller Games—spanning game development, publishing, and community experiences worldwide.

Atari operates internationally with offices in the US, UK, in France, Germany, Sweden, and India.

Overview

We re looking for a DevOps / Build Engineer to own the systems that turn code and content into shippable games across PC and console. You ll sit at the intersection of build engineering, infrastructure, and developer experience: keeping pipelines fast and reliable, automating the painful parts, and making sure builds for every platform come out the door on time.

This is a hands-on role for someone equally comfortable debugging a failing Unreal build pipeline, developing a tool in Go, standing up a Kubernetes workload, and managing a Git server.

If you like making other engineers more productive and you care about robust, observable infrastructure, you ll fit right in.

What You’ll Do

Design, build, and maintain CI/CD pipelines (GitLab, GitHub Actions, Jenkins) for automated multi-platform game builds, tests, and deployments.

Own build automation for major commercial game engines as well proprietary game technology with a retro focus.

Maintain console SDK/devkit toolchains and support platform packaging, certification, and submission workflows for game consoles and PC.

Manage cloud and on-prem infrastructure: AWS (EC2, S3), virtualization (VMware ESXi/vCenter/vSphere, Proxmox), and Linux/Windows servers.

Containerize and orchestrate build and service workloads with Docker and Kubernetes.

Administer and scale source control infrastructure (Perforce, git, SVN, PlasticSCM).

Build internal tooling and automation in Go, C++, Python, PowerShell, and Bash.

Set up and maintain observability across the build and infrastructure stack using

Prometheus, Grafana, and Loki, and respond to issues before they block the team.

Support integrations with game back-end platforms (Steam, Microsoft, Sony, Nintendo).

Partner with global teams of engineering, production, and QA to reduce build times, improve reliability, and streamline release processes.

Requirements Qualifications

Scripting programming: Go, C++, PowerShell, Bash, Python.

CI/CD: GitLab, GitHub Actions, Jenkins.

Game engines: Unity3D, Unreal Engine, Unreal Horde, experience with proprietary C++ engines.

Game SDK devkit experience: Microsoft Xbox Series X|S, Sony PlayStation 5, Nintendo Switch 2, PC (Steam).

Game back-end platforms: Steam, Microsoft, Sony, Nintendo.

Cloud platforms: AWS, AWS S3, AWS EC2.

Containerization: Docker, Kubernetes.

Server administration: Rocky Linux, Ubuntu Server, Windows Server.

Virtualization: VMware ESXi/vCenter/vSphere, Proxmox.

Source control: git, SVN, PlasticSCM, Perforce.

Observability: Prometheus, Grafana, Loki.

Based in Gothenburg area or open for relocation

Excellent communication and collaboration skills

Preferred / Nice-to-Have

Experience shipping game titles through full console certification and release.

Infrastructure-as-code experience (e.g. Terraform, Ansible).

Familiarity with build distribution / caching systems for large game projects.

Background working with distributed teams and large binary asset workflows.
