Senior Software Quality Engineer – Mobile Applications Would you like to help ensure the quality of world-class mobile applications used by millions of users? Join the team building innovative quality engineering solutions for mobile platforms, where your work directly impacts app performance, stability, and the overall user experience.

Sony Interactive Entertainment has a great opportunity within the Quality Engineering organization! We are looking for a motivated and creative Senior Software Quality Engineer (SQE) to define mobile test strategies, drive end-to-end quality, and leverage automation to improve testing across our iOS mobile application ecosystem.

As a Senior Software Quality Engineer, you will work closely with engineering teams to define quality strategies, create comprehensive test plans, execute manual and automated testing, and identify opportunities to expand automation. While this role is not focused on day-to-day software development, candidates should have strong automation experience and be comfortable working with automation frameworks, reviewing automated tests, and partnering with SDETs to improve automation coverage and CI/CD validation.

What You ll Be Doing Lead end-to-end mobile application testing efforts, including defining test strategies, writing test plans, identifying test scenarios, and ensuring comprehensive coverage across new and existing features.

Review product requirements, UX flows, high-level system designs, and architecture diagrams to design effective testing strategies for iOS applications.

Execute manual and automated tests across functional, integration, regression, and end-to-end scenarios using iOS simulators, physical devices, and cloud testing platforms such as Sauce Labs or BrowserStack.

Partner with SDETs and development teams to identify automation opportunities and ensure appropriate automation coverage across the mobile application stack.

Support triaging application issues by analyzing logs, identifying root causes, validating fixes, and working closely with development teams.

File clear, actionable defects supported by logs, reproduction steps, and failure data, and drive them through resolution.

Validate mobile interactions with backend services through API testing and integration testing, including working with mocked dependencies where appropriate.

Drive quality improvements by identifying testing gaps, recommending tooling or process enhancements, and improving overall test effectiveness.

Review and validate automated test coverage and support integration of automated tests into CI/CD pipelines such as Jenkins and GitHub Actions.

Collaborate in an agile, distributed environment with engineering, product, architecture, QA, and operations teams.

What We re Looking For 5+ years of experience in UI, API, and end-to-end testing, with significant hands-on experience testing iOS mobile applications.

Strong experience defining test strategies, creating test plans, and executing comprehensive manual and automated testing.

Experience working with mobile automation frameworks such as Appium and familiarity with Python-based automation.

Understanding of mobile application release lifecycle, including build pipelines, TestFlight, versioning, and release validation.

Experience testing on iOS simulators, physical devices, and cloud testing platforms such as Sauce Labs or BrowserStack.

Familiarity with automation frameworks and tools such as pytest, WebdriverIO, or Playwright, with the ability to review, troubleshoot, and work alongside automation engineers.

Basic programming or scripting experience (Python preferred; Java, JavaScript, or C# is a plus) sufficient to understand automation frameworks, troubleshoot failures, and contribute where needed.

Experience working with CI/CD pipelines such as Jenkins or GitHub Actions.

Strong analytical, debugging, and problem-solving skills with a high sense of ownership.

Excellent collaboration and communication skills, with experience working across globally distributed teams.

Ability to learn quickly and thrive in a fast-paced environment.

Nice to Have Prior experience with PlayStation SDK development.

Experience with GitHub Actions.

Familiarity with PlayStation products and games.
