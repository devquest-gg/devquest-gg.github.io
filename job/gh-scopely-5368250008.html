About The Job

Scopely is looking for a Software Engineer, Jave to join the Royal Lounge Casino Studio team in Bangalore on a hybrid basis.

At Scopely, we care deeply about what we do and want to inspire play every day - whether in our work environments alongside our talented colleagues or through our deep connections with our communities of players. We are a global team of game lovers who are developing, publishing and innovating the mobile games industry, connecting millions of people around the world daily.

The Royal Lounge Casino is a social casino app that continues to evolve, consistently ranking as one of the top-grossing games on the market. Join us to build highly scalable, low-latency systems alongside elite industry talent, making high-impact contributions that reach our players almost immediately.

What You’ll Do

Feature Development: Collaborate with cross-functional team members to design, build, test, and maintain backend features and APIs.

Defensive Coding: Write clean, efficient, and secure Java code adhering to secure software development lifecycle (Secure SDLC) principles.

Collaborative Design: Participate in design discussions and code reviews, offering input on feature architecture while evaluating code for security, performance, and maintainability.

Cross-Functional Alignment: Communicate and collaborate effectively with clients, product managers, and QA teams to clarify requirements, align on delivery milestones, and ensure features meet business objectives and quality standards.

Security Vulnerability Management: Address and remediate security vulnerabilities identified through peer code reviews and automated security scans (SAST/SCA).

Production Support Reliability: Assist with production support, system diagnosis, performance troubleshooting, and applying necessary security patches.

Documentation: Create and maintain accurate technical documentation for systems, APIs, and operational workflows.

What We’re Looking For

Experience: 2+ years of professional software development experience in Java.

Data Core Fundamentals: Strong understanding of Data Structures, Algorithms, Object-Oriented Programming (OOP), and standard design patterns.

API SOA Architecture: Hands-on experience developing in SOA and REST design principles.

Process Collaboration: Experience working in Scrum/Agile environments with excellent communication skills.

Good to Have

Cloud Engineering: Practical experience developing, deploying, and maintaining Java microservices in a cloud-first environment, with hands-on exposure to core AWS services (such as EC2, ECS/Fargate, S3, RDS, and CloudWatch).

Database Systems: Experience working with NoSQL databases (MongoDB preferred).

Secure Programming Knowledge: Solid understanding of common web vulnerabilities (e.g., OWASP Top 10 such as SQL injection, XSS, broken access control) and defensive coding practices (input validation, secure session handling, sanitized logging).

Concurrency: Familiarity with multi-threaded programming concepts and concurrent execution in Java.

Passion for Scale: A strong interest in building low-latency, high-concurrency systems.

(Note: Prior gaming industry experience is NOT required—we are looking for great engineers who love solving complex technical challenges!)

Education: Bachelor’s degree in Computer Science, Software Engineering, or equivalent practical experience.

Bonus Points

Experience with secure coding frameworks or identity/authentication protocols (OAuth2, JWT).

Exposure to automated security analysis tools (e.g., SonarQube, Snyk, Veracode, or OWASP Dependency-Check).

Familiarity with CI/CD automation pipelines

Knowledge or experience with Serverless architectures (e.g., AWS Lambda).
