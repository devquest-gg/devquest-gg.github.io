Game Designer Intern

Gameloft · Hanoi

Entry Design Posted 2026-08-21 Intern
Apply on Gameloft’s site →

WHAT YOU WILL BE WORKING ON Main challenge This role is for those eager to learn the fundamentals of game design and the full game development process. They'll build essential skills and knowledge, then apply them to support real design tasks on live projects, all while leveling up their careers.

What it means on a daily basis Study game design fundamentals and analyze game aspects, including design concepts, controls, and fun factors, across genres Learn the game-making process on a live project and support the main GD on minor tasks.

Contribute to design discussions and decisions.

Write and maintain game design documents (GDDs) for small features, simple gameplay, and improvements to existing features and content (missions, quests, levels), guided by the project game designer.

Learn to find and fix design-related bugs using in-house tools.

Playtest builds with the team.

Opportunities to collaborate and train with Gameloft worldwide experts and develop yourselves.
