Join us and be part of the play! Position Overview:

We are looking for a UI/UX Designer to join the Zynga Poker team. In this role, your primary focus will be crafting high-quality, visually compelling user interfaces and HUD elements while utilizing core user experience principles to ensure seamless gameplay for millions of players globally.

What You’ll Do:

UI / Visual Design Focus: ~70%

Visual Interface Design: Create high-fidelity UI layouts, menus, icon systems, HUD components, and screen flows that align with Zynga Poker’s aesthetic and production standards.

Art Style Brand Alignment: Collaborate closely with the art team to define, refine, and adhere to a unified visual language and thematic art style across all features.

Motion Polish: Design micro-interactions, motion graphics, and functional animations for UI interactions to create feedback and tactile polish.

Engine Integration: Partner with technical artists and engineers to implement visual UI assets, prefabs, and design systems into the game engine effectively.

Asset Production: Consistently produce clean, optimized, production-ready UI art assets for real-time live-ops features.

UX Strategy Focus:~30%

User Flows Wireframing: Develop clear user flows, information architecture, low-to-mid fidelity wireframes, and clickable prototypes for new features.

Usability Research: Participate in usability testing, heuristic evaluations, and competitor research/deconstructs to inform design decisions.

Cross-Functional Collaboration: Partner with product managers and game designers to define feature requirements and ensure player clarity, trust, and engagement.

Community Feedback: Participate in team critiques, product reviews, and feature retrospectives to contribute to UI/UX excellence across the product.

What You Bring:

Education: Bachelor s degree in HCI, Graphic Design, Interaction Design, Visual Design, or a related field (or equivalent practical experience).

Experience: 3–5 years of experience in game development or interactive media specializing in UI/UX, with experience shipped on at least 1–2 titles.

UI Visual Expertise: Advanced proficiency in visual hierarchy, layout design, typography, color theory, iconography, and asset creation for mobile or cross-platform games.

UX Prototyping: Solid working knowledge of UX design practices, including wireframing, user flows, rapid prototyping, and user psychology principles.

Tooling: Proficient with industry-standard design tools (e.g., Figma, Adobe Creative Suite, Unity UI tools, or similar game engine interfaces).

Adaptability Collaboration: Strong communication and collaboration skills with the ability to articulate visual design choices to cross-functional teams in a fast-paced live service environment.

Portfolio: A portfolio demonstrating strong visual UI design execution, polished game UI assets, motion/micro-interactions, and supporting UX documentation (wireframes, flows).
