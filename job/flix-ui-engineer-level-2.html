Role and Purpose: We are looking for a talented and motivated  UI Engineer with solid  frontend  development experience to help create polished, performant game UI using Coherent  Gameface  for our Unreal Engine projects. This role is ideal for someone who has already shipped UI features, is confident with modern web technologies, and is ready to take ownership of  existing  UI systems.

Responsibilities: Build and maintain in-game UI using HTML5, CSS, JavaScript/TypeScript, and Gameface runtime tools.

Implement UI interactions such as gamepad navigation and keyboard inputs using the Gameface Interaction Manager.

Work closely with Designers and Gameplay Engineers to translate UI mockups and prototypes into functioning game interfaces.

Integrate UI with Unreal Engine systems, ensuring reliable data flow and gameplay connection.

Debug, profile, and optimise UI for performance and memory efficiency across multiple platforms.

Contribute to improving UI workflows, documentation, and reusable component patterns.

Diagnose and fix defects and support the team in doing so.

Mentor junior engineers and support seniors, suggesting and acting on process improvements.

Stay current with industry trends, tools, and Gameface/Unreal advances.

Requirements: 2–4 years of experience in modern frontend development (HTML5, CSS3, TypeScript).

Experience building UI with Coherent Gameface or similar web based UI frameworks embedded in games.

Strong understanding of component driven UI architecture.

Familiarity with responsive layout, animations, and web performance best practices.

Awareness of platform-specific constraints when building and optimising UI.

Familiarity with  Unreal Engine  workflows and data binding between gameplay and UI.

Good debugging skills across UI logic, interaction, and engine integration.

Ability to work independently on features while collaborating effectively within a multidisciplinary team.

A keen eye for detail and polish – ensuring UI matches designs, feels responsive, and behaves consistently across screens and input methods.

Desirable Skills & Technologies: Experience with Unreal Engine (Blueprints or C++).

Experience with Unreal UI (UMG and/or Slate).

Hands-on work with Gameface UI component libraries.

Experience with a modern front-end framework (React / Angular).

Console development exposure (PlayStation, Xbox, Switch).

Familiarity with advanced CSS effects, transitions, or UI animation workflows.

Understanding of multiplayer UI, HUD systems, or live-ops UI updates.

Application & Portfolio: Please include your CV, portfolio and cover letter (optional) within your application. If your examples are from previous works with another studio, please make sure samples are cleared for release by copyright owners. Links to an online portfolio are preferable, otherwise we accept showreels via Dropbox or other secure sharing platforms.
