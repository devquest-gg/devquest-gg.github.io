ABOUT US

Scorewarrior is a game developer and publisher based in Limassol, Cyprus.

We are working on Total Battle — a cross-platform MMO 4X strategy game with a deep social system and extensive player interaction. We have 2 million monthly active players and are continuing to grow, with the goal of becoming the #1 game in the genre.

Our team consists of 200+ passionate, talented, self-driven, and continually developing professionals who love making high-quality games.

ABOUT THE ROLE

At Scorewarrior, we're making a long-term investment in Building Blocks — a new generation of self-service internal products with clear interfaces, contracts, and documentation that game teams can adopt independently.

Localization Hub is the first Building Block.

Today, Localization Hub, together with Crowdin, powers localization workflows across Scorewarrior — from translation tracking, analytics, and reporting to automated translation quality checks and an AI-powered localization assistant.

Our next goal is to transform Localization Hub into the first fully self-service Building Block, enabling content teams to localize standard features independently while the lead focuses on high-level decisions.

The engineering team behind Localization Hub will establish the architecture, engineering standards, and practices that future Building Blocks will build upon.

WHAT WE'RE LOOKING FOR

We're looking for a Staff Frontend Engineer to design and build the portal's micro-frontend platform and a shared component library. Localization Hub will be the first module.

WHAT YOU’LL DO

- Design the micro-frontend platform architecture and defend the solution

- Develop the portal Core and the module contract

- Set up module delivery: template, CI/CD, documentation

- Migrate the current Localization Hub as the first module of the portal

- Build a shared component library based on Atomic Design and Storybook, contributing to its visual design as well

- Set standards for module teams and help them onboard to the portal

- Maintain high code quality through testing, code reviews and documentation

- Own portal performance: loading time, bundle size budgets and rendering speed across modules

- Investigate and resolve frontend production issues, including layout bugs, interaction quirks and degraded performance

- Collaborate with backend engineers, module teams and product to align on APIs, requirements and platform priorities

- Take part in planning and scoping the platform roadmap, and drive upgrades of shared dependencies across modules

- Mentor engineers and help improve team practices in frontend architecture, testing and performance tuning

WHAT YOU SHOULD HAVE

- 5+ years of commercial frontend development experience

- Deep knowledge of React and TypeScript

- Strong HTML and modern CSS skills, and the ability to build well-structured, reusable and responsive components

- Experience building a micro-frontend platform in production with React, TypeScript, Vite and React Router: Module Federation, Next.js Multi-Zones, import maps or similar, and independently versioned npm modules

- Frontend CI/CD experience: environment-based rollouts, CDN, versioned releases and rollbacks

- Experience creating or evolving a design system and Storybook

- Experience writing unit, integration and end-to-end tests (Vitest or Jest, Playwright)

- Understanding of performance, accessibility and web security

- Ability to justify decisions in writing (design documents, ADRs)

NICE TO HAVE

- Experience with state and data management in React: Zustand, Redux Toolkit, TanStack Query
