DESCRIPTION OF DUTIES

Build and maintain automated tests and SDET-style tooling.

Develop, maintain, and improve tests for Nintendo s systems

Perform deep troubleshooting and root-cause analysis for low-level, concurrent code.

Work with engineering teams to resolve defects and improve reliability.

Create practical, creative solutions to difficult technical problems.

Support CI systems and automated regression detection.

SUMMARY OF REQUIREMENTS

5+ years of software engineering or software test engineering experience.

Strong C and modern C++ programming skills, with experience developing high-performance, low-level software.

Strong understanding of networking as a software developer, including implementing, testing, debugging, and troubleshooting network protocols and networked applications.

Hands-on experience developing network socket code using TCP/IP and UDP, including socket APIs, connection management, packet handling, timeouts, retries, and error handling.

Experience implementing and testing networking protocols and functionality such as TCP/IP, UDP, DNS, DHCP, HTTPS, and TLS/SSL.

Strong understanding of packet-level networking and experience analyzing network traffic using Wireshark, tcpdump, or similar tools.

Experience developing automated tests for networking software, including functional, integration, stress, reliability, concurrency, and failure/recovery testing.

Strong multithreading and concurrency skills, with the ability to develop and debug low-level concurrent C/C++ code.

Experience debugging complex networking software using debuggers, logs, packet captures, core dumps, and other low-level debugging techniques.

Experience building and running software across Windows, Linux, and embedded environments.

Ability to collaborate across development, test, and other engineering teams to solve complex technical problems.

Degree in Computer Science, Computer Engineering, Electrical Engineering, or a related field, or equivalent experience.

Important : This is a software engineering/SDET role focused on developing and testing networking code. Candidates should have hands-on programming experience with network protocols and socket APIs. This role is not focused on network administration, cloud networking, infrastructure deployment, network configuration, or simply connecting and managing networks.

Applicants must be legally eligible to work in the United States to be considered. Visa sponsorship is not available for this role.

This position is onsite in Redmond, WA, and not open to remote status at this time.
