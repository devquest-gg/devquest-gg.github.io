Client Engineer

FirstFun

Mid Engineering Posted 2026-10-06 Full time
Apply on FirstFun’s site →

Key Responsibilities Own the technical design, development, testing, release, and ongoing maintenance of mobile game client modules, ensuring reliable, high-quality delivery of requirements.

Independently implement client systems for core gameplay, UI interactions, and character presentation, working with game designers, artists, and technical artists to refine the player experience.

Design and maintain a clear, extensible client codebase that supports version updates, in-game events, and long-term live operations.

Work with server engineers to define APIs, data synchronization, and error handling, and integrate networking features, remote configuration, and analytics reporting.

Analyze and optimize CPU and GPU performance, memory usage, loading times, and network performance on mobile devices; resolve crashes, stuttering, and device compatibility issues.

Participate in code reviews, technical design discussions, and incident reviews to improve code quality, test coverage, and delivery efficiency.

Collaborate with product managers, game designers, QA, and other cross-functional teams to break down technical tasks, identify risks, and drive issues through to resolution.

Requirements Bachelor’s degree or higher in Computer Science, Software Engineering, or a related discipline, with at least 3 years of game client development experience.

Proficiency in C# or C++, with project development experience using Unity, Unreal, or a comparable real-time game engine.

Experience with a released game or a complete project, with the ability to independently own client features from development and integration testing through to release and maintenance.

Familiarity with common client architectures, data structures, and software design approaches, with the ability to write stable, maintainable, performance-conscious production code.

Experience in mobile debugging and performance profiling, with an understanding of how device differences, memory, loading, frame rate, and network conditions affect games.

Strong communication and collaboration skills, with the ability to conduct code reviews, share knowledge, and work effectively with game design, server engineering, QA, and other teams.

Preferred Qualifications Experience launching mobile games or supporting long-term live operations, with familiarity with event updates, hot updates, asset package splitting, or remote configuration.

Experience building gameplay frameworks, UI frameworks, asset loading systems, network synchronization systems, or performance diagnostic tools.

Practical experience with automated testing, continuous integration, crash monitoring, or AI-assisted development tools.

Why Join Us You will help build core mobile game experiences and the client engineering foundation, working closely with cross-functional teams to continuously improve game quality, iteration efficiency, and the player experience.
