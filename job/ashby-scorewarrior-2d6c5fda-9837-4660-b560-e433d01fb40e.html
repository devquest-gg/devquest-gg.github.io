Game Backend C++ Engineer (Gameplay team)

Scorewarrior · Limassol Cyprus

Mid Engineering Onsite Posted 2026-04-28 Full time
Apply on Scorewarrior’s site →

Scorewarrior is a game developer and publisher based in Limassol, Cyprus. The company focuses on the 4X strategy genre, with an ambitious goal to grow its hit game, Total Battle, to become the No.1 strategy game in the world. Our team consists of 200+ passionate, talented, self-driven, and continually developing professionals who love making high-quality games.

Our product: We are currently working on Total Battle — an MMO 4X strategy game with a deep political system and lots of player interaction. Players take on the role of a commander and need to develop their city, forge alliances, fight against monsters, and conquer other players. We're constantly developing new game mechanics, and the project is continuing to grow.

Our game project has a code base of ~300k SLOC and consists of multiple services running in several hundred instances. The game services are a sharded system for horizontal scaling.

Our team is looking for both Middle and Senior specialists with confident knowledge of C++ and design principles to work on creating new game features for a large-scale multiplayer project with long-term gameplay.

Our team's objective and the challenge they face is to create an outstanding technical design that ensures quality, flexibility, and simplicity in the development of in-game features.

Tasks:

- Design and implement solutions for new game mechanics — based on documentation from game designers, create a technical design and implement it.

- Prepare RFC documents describing your approach and discuss them with the team before implementation.

- Deliver your solution to production and ensure it runs smoothly by monitoring its behavior after deployment.

- Refactor and optimize existing functionality to improve performance, maintainability, and scalability.

- Perform code reviews for other team members and follow team coding guidelines and best practices.

- Create functional prototypes to validate ideas and mechanics when necessary.

- Write and maintain technical documentation for implemented features and decisions.

- Participate in team meetings and discussions to stay aligned on priorities and progress.

Requirements:

- Strong communication skills and initiative.

- 3+ years of experience developing in C++ in a product-oriented company

- At least 2 years of backend development experience (not necessarily in C++)

- Solid knowledge of software design principles and ability to apply them in practice.

- Ability to analyze and decompose complex tasks into smaller, manageable steps.

- Practical experience with network and multithreaded programming

- Practical experience with relational databases

- Proficiency in Linux environments for development and debugging.

- Knowledge or willingness to learn Python for developing tools and automation.

The following would also be to your advantage:

- Having samples of code that you can show us.

- Knowledge of other high-level programming languages (for general awareness).

- Practical experience applying Domain-Driven Design in real-world projects

- Hands-on experience building applications using Akka.NET http://Akka.NET, Microsoft Orleans, or similar actor-based frameworks

We use:

- C++20, Clang, and CMake.

- Boost — only for the library, not for game code.

- PostgreSQL.

- GitLab, TeamCity, Ansible.

- SonarQube, Clang-Tidy, Clang-Format.

- Onboarding, coding conventions.

- Python for utilities.

- Linux.

Our technical developments:

- A library/framework of ready-made solutions for creating game features.

- ORM — allows us not to have to write code for saving to the DB.

- A code generator for a binary RPC protocol and ORM.

- A pub/sub event system for game clients.

- Telemetry that allows for real-time product status tracking (through Grafana).

- An expression interpreter for flexibility in game configuration.

- HotReload environment, with everyday game updates.

- Sync and Async network designs.

- Internal Event System.

- Internal persistent and transactional message system.

- R-tree based world map.
