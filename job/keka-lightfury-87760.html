Role: UI & 2D Artist Experience: 3-5 years Location: Bengaluru Employment Type: Full-time / On-site About the Role We are looking for a talented UI & 2D Artist to join our game art team. In this role, you will create engaging 2D visuals and intuitive UI designs for mobile games.

You will work closely with Game Designers, Artists, Animators, and Developers to turn game concepts into polished and player-friendly visuals.

Key Responsibilities Create 2D game assets such as icons, buttons, backgrounds, illustrations, and other visual elements.

Design attractive and user-friendly Game UI/UX .

Create UI screens, menus, pop-ups, HUDs, and in-game interfaces.

Develop game icons, badges, currencies, rewards, and promotional assets .

Maintain visual consistency across different game screens and assets.

Create wireframes and visual concepts based on game requirements.

Work with developers to ensure UI assets are implemented correctly in the game.

Iterate on designs based on feedback from the design and art teams.

Follow established art styles and contribute ideas to improve the game's visual quality.

Optimize assets according to mobile game requirements.

Requirements 3-5 years of experience in 2D Game Art, UI Art, or a similar role.

Strong understanding of 2D art, composition, colour, typography, and visual hierarchy .

Good knowledge of Game UI/UX principles .

Strong skills in tools such as Photoshop, Illustrator, Figma, or similar software .

Understanding of mobile game UI and different screen resolutions .

Ability to create clean, polished, and production-ready assets.

Good communication and collaboration skills.

Ability to take feedback and work within deadlines.

A strong portfolio showcasing 2D artwork and game UI is required.

Good to Have Experience working on mobile games .

Knowledge of Unreal Engine and basic understanding of UI implementation.

Basic knowledge of 2D animation/motion graphics .

Experience creating assets for live games and working with frequent iterations.

Understanding of game art pipelines and asset optimization.

What We’re Looking For We are looking for someone who is: Creative and detail-oriented.

Passionate about games and game art.

Comfortable working in a fast-paced environment.

Able to independently handle tasks from concept to final asset.

Good at balancing art quality, usability, and game requirements .

Portfolio Candidates should share a portfolio containing: Game UI screens HUDs / menus / pop-ups Icons and buttons 2D game assets Illustrations or backgrounds Any shipped game work, if available Note: Candidates with strong game UI/2D art portfolios will be preferred.
