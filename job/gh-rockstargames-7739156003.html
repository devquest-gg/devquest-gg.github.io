Senior Web Developer - Tools

Rockstar Games · Edinburgh

Senior Engineering Onsite Posted 2026-05-20 Full time
Apply on Rockstar Games’s site →

At Rockstar Games, we create world-class entertainment experiences.

Become part of a team working on some of the most rewarding, large-scale creative projects to be found in any entertainment medium - all within an inclusive, highly-motivated environment where you can learn and collaborate with some of the most talented people in the industry.

Rockstar is on the lookout for a passionate Web Developer with strong experience in React and .NET to help build modern, scalable applications that help power our complex productions. This role works closely with designers, back-end engineers and stakeholders across the organisation to deliver high quality user experiences.

This is a full-time, permanent and in-office position based in Rockstar’s state-of-the-art game development studio in Edinburgh, Scotland.

WHAT WE DO

The Rockstar Games Tools Team create and maintain software tools that are used by all game development disciplines to support the creation of all Rockstar Games projects.

RESPONSIBILITIES

Design and develop complex, high performance web applications that are the backbone of project management and collaboration across our projects.

Development of accessible front-end components and applications using React.

Integration of front-end applications with ASP.NET Core (C#).

Contribute to architectural decisions and continuous improvement of the code base.

Develop comprehensive test suites.

Web performance optimization.

REQUIREMENTS

A degree in computer science or 5+ years of experience in professional web development.

5+ years of experience using React.

5+ years of experience using .NET.

Experience with real-time technologies e.g. WebSockets, SignalR.

Experience with automated testing, shared code, and source control.

Knowledge of Agile, software development, and web-security best practices.

Passion for web technologies and a desire to remain up to date with the latest technologies.

PLUSES

Please note that these are desirable skills and are not required to apply for the position.

Knowledge of authentication/authorization systems e.g. OAuth, identity providers.

Experience working on chat, collaboration or messaging platforms.

Understanding of UI/UX principles and/or working closely with design systems.

Exposure to Elasticsearch/OpenSearch.

Exposure to observability tools.

Knowledge of Rockstar’s game titles and passion for playing video games.

HOW TO APPLY
