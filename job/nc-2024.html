Junior QA Mobile Game Tester

Nordcurrent · Vilnius

Entry QA Posted 2023-06-05 Full time
Apply on Nordcurrent’s site →

You will join the biggest Lithuanian gaming studio – a team of 250 people passionate about creating world-class games. And you will start with That’s right – testing games! You will identify and describe issues in the games and solve them by communicating with development teams. Further on, you will create testing scenarios, automate testing, improve it to make the whole process of quality assurance more efficient and reliable.

Your Key Responsibilities:

Execute manual mobile video game testing

Functional Tests:

Execute the test scenarios outlined in the test plan to verify the new features work correctly.

Perform smoke testing to verify the most crucial functions of the game.

Perform regression testing to confirm that new updates have not adversely affected existing features.

Carry out confirmation testing to verify the resolution of previously identified issues.

Non-Functional Tests:

Assess game performance by evaluating game factors like load times, frame rate, and resource usage.

Evaluate usability by ensuring the game is user-friendly and intuitive.

Ensure game compliance with platform standards and regulations.

Conduct basic localization testing to check the game s adaptability to different languages and regions without full-scale localization testing.

Identify game defects and report findings.

Monitor games production environments for any irregularities or disruptions.

Maintain effective communication with game developers and diverse cross-functional teams.

A Successful Candidate Must Have:

Have a strong knowledge of testing theory.

Ability to spot and identify defects easily.

Demonstrate good spoken and written English language skills.

Possess thorough knowledge of operating systems and the broader mobile technology landscape.

Love for mobile video games.

Extra Great to Have:

Proficient in using bug tracking systems.

Certification in testing courses.

Some experience in software quality assurance.

Salary: from 1440 EUR/month (gross)
