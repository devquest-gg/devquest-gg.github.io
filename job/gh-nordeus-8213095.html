Do you dream about developing infrastructure and pipelines for handling and processing petabytes of data?

What if we told you that this actually helps us make decisions that make millions of gamers happy.

Interested? Well Neo, get into the Matrix, it’s your time to shine!

WHAT YOU’LL DO:

Build large-scale data pipelines that process billions of events every day with data processing frameworks like Airflow, Kafka, BigQuery and Google Cloud Platform

Design and develop our self-service Data Warehouse and Business Intelligence platform that enables our game teams to utilize data to bring the best experience to our players

Design and develop ML pipelines to help our data scientists efficiently develop new ML models using our game data Use best practices in continuous integration and delivery

Help drive optimization, testing and tooling to improve data quality

WHO YOU’LL WORK WITH:

You will work other data engineers and different teams across Nordeus including Data Scientists, Business Analysts, Performance Marketing and Product teams

WE ARE A MATCH, IF YOU:

Are pursuing (or recently completed) a degree in Computer Science, Software Engineering, or a related field Have a solid understanding of software design principles, object-oriented programming, patterns, algorithms and data structures

Have coding skills in Python, Java, C# or similar languages and relational databases

Are passionate about building data pipelines and excited by the challenge of working with large-scale data

Are curious about how game data can be collected, processed, and used to inform business decisions and build better experiences for players

BONUS POINTS:

Not required, but let us know if you have experience with any of the following:

Data frameworks like Airflow, Prefect, Dagster, Astronomer, AWS Step Functions, Azure Data Factory or similar

Big data platforms like: BigQuery, AWS Redshift, Azure Data Warehouse, SnowFlake, Databricks, Teradata, Hive, Presto or similar

Stream processing like: Kafka, Google Pub/Sub, Amazon Kinesis, Azure Events Hub, RabbitMQ and similar

ETL, data warehouse, data modelling, data access, and data storage techniques

Cloud providers GCP/ AWS/ Azure

Any hands-on experience with SQL
