Development Tester

Ubisoft (HQ) · Chengdu

Senior QA Posted 2026-08-29 Full time
Apply on Ubisoft (HQ)’s site →

1. Conduct functional, regression, exploratory, smoke and risk-based special testing for games across console and mobile platforms, covering gameplay, UI, audio and other modules. Verify online versions and hotfixes prior to official release.

2. Design and maintain test cases via Xmind, Jira, TestRail and other tools, covering normal, boundary and abnormal scenarios. Review requirements in advance to identify quality risks.

3. Reproduce and locate bugs, document detailed fault information, severity levels and impact scope on Jira in a standardized manner. Follow up on bug fixes, perform regression retests, and assist developers in root cause analysis.

4. Adapt to Agile workflows including Scrum and Kanban, and attend all routine iteration meetings. Process Test Requests, and align requirements cross-functionally with developers, designers, artists and overseas WWQC teams.

5. Report testing progress in both Chinese and English and provide required documentation. Improve work efficiency with Python and AI tools, and implement basic test automation where feasible.

6. Optimize testing procedures, share testing experience, unify team testing standards and circulate proven testing practices within the team.

1. Familiar with testing methodologies including black-box testing, regression testing and exploratory testing. Able to design test cases with boundary value analysis, equivalence partitioning and module decomposition.

2. Capable of reading client and server logs for basic troubleshooting. Knowledge of Unity or Unreal engines is preferred. Console testing experience is a bonus.

3. Proficient in mainstream testing tools including Jira and Xmind.

4. Skilled in oral and written Chinese and English to support daily collaboration with global teams.

5. Able to work under tight deadlines and adapt to shifting work priorities. Capable of independently delivering testing tasks within scope.

6. Passionate about gaming with strong focus on player experience; equipped with solid cross-department communication and teamwork skills.

1. Basic programming skills to develop simple automated test scripts.

2. Hands-on experience using AI tools to facilitate case writing, log analysis and bug organization.

3. Familiar with end-to-end game development pipelines and cross-discipline collaboration workflows.
