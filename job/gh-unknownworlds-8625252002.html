Technical UI Designer

Unknown Worlds · Remote · Remote

Mid Design Remote Posted 2026-07-09
Apply on Unknown Worlds’s site →

THE OPPORTUNITY

Unknown Worlds is looking for a Technical UI Designer to help build the next game in the Subnautica franchise. In this role, you will own the implementation and polish of player-facing UI, partnering closely with UI/UX design, art, and engineering to create accessible, intuitive, performant interfaces across all target platforms.

While UI is a main focus for this role, there will be an opportunity to work on the technical design of other features.

This is a full-time remote position on a globally distributed team.

RESPONSIBILITIES

Own UI implementation from wireframe through final polish across all target platforms.

Break down UI features into widgets, structures, classes, and data-driven components that support gameplay needs.

Collaborate with UI/UX design, UI art, technical design, and engineering to deliver interfaces that are functional, performant, accessible, and visually polished.

Implement responsive animations and interactive UI behavior that react to gameplay events, player input, and internal UI states.

Advise on implementation approach, including Blueprint vs. native code, architecture, structure, and workflow choices.

Optimize and debug UI/UMG and Blueprint issues to meet platform performance targets.

Improve Technical UI Design workflows, pipelines, organization, and documentation; contribute feedback throughout the UI creation process.

QUALIFICATIONS

5+ years of experience as a Technical UI Designer, including at least one shipped Unreal Engine title in a Technical UI Designer role.

Proficiency with UMG, Blueprints, and Enhanced Input.

Strong understanding of Unreal UI architecture, lifecycle events, state management, and UI-specific performance considerations.

Experience implementing animated, responsive, data-driven UI components such as HUDs, health bars, popups, and action prompts.

Deep understanding of UI/UX, game usability, interaction design, visual design, and modern video game UI best practices.

Strong debugging and documentation skills, with the ability to diagnose visual and logic-related UI issues.

Self-starting, organized, collaborative, and comfortable working remotely with minimal oversight.

Strong written, verbal, and visual communication skills.

Good understanding of art fundamentals, animation, and aesthetic judgment.

PREFERENCES:

Programming experience in C++, C#, or similar languages.

Familiarity with UI asset creation tools such as Photoshop or Illustrator.

Experience developing under an early access release model.

Experience creating UI materials.

Familiarity with UMG Viewmodels.

Familiarity with using 3D models in UI interfaces.
