About the Role LightFury Games is looking for a Tools Programmer II to build and maintain tools that improve the productivity and efficiency of our gameplay development team. In this role, you'll work closely with Gameplay Programmers, Technical Artists, Designers, and other engineers to create robust editor tools, automation workflows, and debugging utilities that streamline game development.

This is an excellent opportunity for an engineer who enjoys solving technical challenges, building developer-facing tools, and improving production pipelines.

Key Responsibilities Design, develop, and maintain internal tools that support gameplay programming and content creation.

Build editor extensions, debugging tools, and automation workflows to improve development efficiency.

Collaborate closely with Gameplay Programmers to understand workflow bottlenecks and develop effective tooling solutions.

Develop utilities for asset management, data validation, profiling, and performance analysis.

Optimize existing tools for usability, scalability, and maintainability.

Troubleshoot technical issues and provide tooling support across gameplay development.

Write clean, modular, and well-documented C++ code following engineering best practices.

Participate in code reviews and contribute to the continuous improvement of development workflows.

Support the integration of gameplay systems with internal tools and pipelines.

Required Skills & Qualifications 4–6 years of professional experience in C++ software development.

Strong proficiency in C++ with solid understanding of object-oriented programming and software design principles.

Experience developing tools, editor extensions, or developer utilities.

Strong debugging and problem-solving skills.

Good understanding of data structures, algorithms, and performance optimization.

Experience working with version control systems such as Git or Perforce.

Ability to collaborate effectively with cross-functional teams.

Preferred Qualifications Experience with Unreal Engine (preferred) , including editor tooling or plugin development.

Experience with graphics APIs such as Vulkan or OpenGL .

Knowledge of game development pipelines and gameplay programming workflows.

Experience with build systems, scripting, or automation tools.

Familiarity with profiling, debugging, and optimization tools.

Understanding of multithreaded programming is a plus.
