Snowdrop is a powerful game engine that enables Ubisoft content creators to set their creative minds free. Fast and flexible, Snowdrop gives developers innovative tools designed from the ground up for creating the unknown.

Snowdrop provides the perfect canvas for game developers to create the games of the future.

&#xa0;

Working in our World Tech rendering team, your primary focus will be on implementing, extending, and maintaining the various World Rendering Systems of our in-house engine Snowdrop™. As a render programmer you will be part of a very committed R&D team working with multiple hardware platforms. You will be expected to work in collaboration with other programmers, artists and testers to craft high quality, scalable world building solutions that bring Snowdrop and its various titles to an even higher and more performant standard.

What you'll do Design, implement, and iterate on rendering features for large, open-world environments (terrain, vegetation, foliage, and world composition systems) Work with C++ Develop world rendering features that scale across multiple platforms and different hardware capabilities Balance visual quality, streaming, and level-of-detail (LOD) strategies with memory footprint and runtime performance across massive, seamless worlds Keep the existing world rendering pipeline and tools up to date in accordance with the latest changes that occurred in the development pipeline (e.g. new SDKs, middleware versions, or graphics APIs) Communicate with the teams that use the technology in order to understand their requirements and to define the implementation and improvement needs for world rendering tech

&#xa0; What you'll bring as technical skills Professional experience with C++ programming Experience with performance critical and/or rendering programming Solid understanding of graphics APIs and modern rendering pipelines Ability to accurately predict task duration and understand dependencies Strong debugging skills Have awareness of new developments in graphics APIs and hardware Knowledgeable about the internal tools used in the video game production pipeline &#xa0;
