Skeleton Key is a game development studio and division of Wizards of the Coast. We are a group of people who are guided by the belief that by empowering our teams and providing the necessary time, tools, and support we can foster a creative culture where everyone can do their best work.

Skeleton Key is headquartered in Austin, TX, and we’re building out a new, growing studio in Montreal, QC. We’re looking for a talented UI Scripter with a passion for creating intuitive, responsive game interfaces. You’ll join our Montreal team to implement and connect UI features in Unreal Engine, helping bring our first AAA game to life.

What You ll Do:

Implement and hook up game UI using Unreal UMG and Blueprints.

Connect menus, HUDs, and widgets to gameplay systems and data.

Build reusable UI components and support established UI frameworks.

Implement navigation and input for controller, mouse, and keyboard.

Debug UI logic, layout, performance, and integration issues.

Collaborate with UI/UX, art, design, and engineering.

What You ll Bring:

Experience building UI in Unreal using UMG and Blueprints.

Understanding of Blueprint scripting, events, interfaces, and data flow.

Strong debugging and problem-solving skills.

Familiarity with UI navigation, input, scaling, and localization.

Ability to create clear, maintainable implementations from designs.

Strong communication skills and a collaborative mindset.

Nice To Have:

Experience with Unreal Common UI.

Familiarity with C++ or console development.

Professional game experience or a relevant portfolio.
