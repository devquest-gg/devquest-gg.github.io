We’re looking for an experienced Unity Tech Lead to join the Picture Blast Solitaire team.

What are you working on?

- Genres: Puzzle, Casual

- Platforms: iOS, Android, Mobile

For which tasks (responsibilities)?

- Audit the project (game and content loading, builds, release process, critical code areas) and maintain a prioritized technical backlog

- Own content delivery: loading speed, caching, versioning, removal of outdated content, close collaboration with the backend team

- Ensure A/B tests and LiveOps events can be launched, stopped, and run in parallel without performance degradation

- Keep stability at target levels: ANRs, crashes, performance on low-end Android devices

- Build monitoring and automation tools; set up dashboards together with analysts

- Estimate tasks, identify technical risks to timelines, and find solutions

- Establish code review and release preparation processes; define criteria for when tasks are ready for QA

- Take part in project planning with producers, factoring business goals into technical decisions

- Develop game features end to end: gameplay logic, UI implementation from mockups, integration with content and configs

What kind of professional are we looking for?

- 6+ years of commercial development with Unity/C#, including mobile F2P projects in production

- Experience at a product company working on a live project with regular updates

- Hands-on experience with Addressables at scale: remote catalogs, bundle dependencies, content updates without a store release

- Delivering heavy content to the client: background downloading, prioritization, caching, handling poor network conditions

- Working with textures and atlases at scale: compression, memory, bundle size

- Mobile optimization: profiling, memory, draw calls, low-end Android devices, ANRs

- Client-side integration of A/B tests and remote config; working with product analytics

- Experience building modular architecture in Unity using DI frameworks (Zenject, VContainer, or similar) and async approaches (UniTask or similar)

- Experience making technical decisions on a project: architecture, tech debt, prioritization, estimates

- Experience using AI tools in development

Nice to have

- Building LiveOps systems: event frameworks, config-driven management, scheduling, delivery and removal of event content

- Ad monetization (AppLovin MAX)
